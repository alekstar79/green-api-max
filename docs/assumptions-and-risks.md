# Допущения и риски

## Подтвержденные ограничения

- Хост приложения задается через `VITE_API_URL`; если переменная отсутствует или пуста, используется `https://api.green-api.com/v3`. `API_URL` и `MEDIA+URL` не используются приложением.
- Форма подключения содержит только `idInstance` и `apiTokenInstance`.
- `.env.local` используется позднее только для локальных тестов с живым API; содержимое файла не выводилось и не должно попадать в Git.

## Допущения

| Тема                    | Допущение                                                                                            | Обоснование                                                                                                      | Пересмотр                                                                       |
| ----------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Хранение учетных данных | Учетные данные хранятся только в памяти вкладки.                                                     | Минимизирует время хранения секрета; вход заново после перезагрузки приемлем для минимального тестового клиента. | Если потребуется переживать перезагрузку, согласовать способ хранения отдельно. |
| Активный диалог         | MVP одновременно показывает один активный чат.                                                       | Требование описывает создание и использование одного чата; история не загружается из API.                        | Если нужен список/переключение нескольких диалогов, это расширение требований.  |

| Пустой ответ long-poll  | При пустом ответе long-poll по таймауту цикл продолжает опрос без ошибки.                            | Документация описывает пустой ответ по таймауту.                                                                 | Уточнить форму пустого ответа в моках/живой проверке без догадки о схеме.       |
| Совместимость React     | Для начальной реализации предпочтительна совместимость с React 18/19 вместо привязки к одному major. | Версия React в задаче не задана.                                                                                 | Проверить фактическую версию при инициализации проекта.                         |

## Риски и открытые проверки

| ID       | Риск                                                                                                                                                             | Вероятность / влияние | Снижение риска                                                                                                                      |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| RISK-001 | Универсальный хост `api.green-api.com/v3` не прошел TLS-проверку из текущего окружения (`curl` завершился `SSL_ERROR_SYSCALL`).                                  | Средняя / высокая     | Проверить повторно из браузера и через живой запрос с локальными учетными данными; не подменять хост на `API_URL` без согласования. |
| RISK-002 | Проверка CORS была успешна на кластерном хосте, но это не подтверждает CORS универсального хоста.                                                                | Средняя / высокая     | Пройти preflight/вызов именно заданного хоста после выяснения сетевой доступности.                                                  |
| RISK-003 | Входящие уведомления требуют конфигурации инстанса: пустого `webhookUrl` и включенного `incomingWebhook`.                                                        | Resolved              | `incomingWebhook=yes` подтвержден; событие от второго аккаунта принято, `DeleteNotification` вернул `result: true`.                 |
| RISK-004 | Очередь уведомлений общая для инстанса и FIFO; ack неподдерживаемых событий необходимо делать, иначе очередь не продвинется.                                     | Средняя / средняя     | Фильтровать тип, не отображать медиа; после безопасного разбора подтверждать событие; дедуплицировать повтор по `idMessage`.        |
| RISK-005 | `SendMessage` может вернуть `idMessage` при принятии в очередь, что не гарантирует фактическую доставку.                                                         | Средняя / средняя     | В интерфейсе показывать «принято API», не «доставлено».                                                                             |
| RISK-006 | `.env.local` существует, но рабочая папка пока не является Git-репозиторием; исключение из Git проверено по правилу, однако `git check-ignore` выполнить нельзя. | Средняя / высокая     | Добавлен `.gitignore`; перед инициализацией Git отдельно проверить игнорирование и отсутствие секретов в индексе.                   |
| RISK-007 | Публичный `web.max.ru` отдает страницу авторизации, а не интерфейс чата; дизайн активного состояния нельзя сверить визуально.                                    | Высокая / средняя     | Используем доступное описание интерфейса; визуальное сравнение активного чата оставляем ручной проверке.                            |

## Вопросы

На текущем этапе новых блокирующих вопросов нет. Universal host остаётся заданным ограничением пользователя, его доступность зафиксирована как риск на проверку, а не заменяется другим URL.

### Статус этапа 3

- `OPTIONS` на `VITE_API_URL` из `.env.local` вернул `204`, `Access-Control-Allow-Origin: *` и разрешенные GET/POST/DELETE методы. Проверка выполнена без учетных данных.
- Universal fallback `https://api.green-api.com/v3` остается непроверенным из-за TLS handshake `SSL_ERROR_SYSCALL` в этом окружении.
- Живой E2E со вторым аккаунтом пройден: CheckAccount, доставка SendMessage, входящее текстовое событие ReceiveNotification и DeleteNotification с `result: true`.
