# Допущения и риски

## Подтвержденные ограничения

- Хост приложения задается через `VITE_API_URL`; если переменная отсутствует или пуста, используется `https://api.green-api.com/v3`. `API_URL` и `MEDIA+URL` не используются приложением.
- Форма подключения содержит только `idInstance` и `apiTokenInstance`.
- `.env.local` используется позднее только для локальных тестов с живым API; содержимое файла не выводилось и не должно попадать в Git.

## Вопросы

На текущем этапе новых блокирующих вопросов нет. Universal host остаётся заданным ограничением пользователя, его доступность зафиксирована как риск на проверку, а не заменяется другим URL.

### Статус этапа 3

- `OPTIONS` на `VITE_API_URL` из `.env.local` вернул `204`, `Access-Control-Allow-Origin: *` и разрешенные GET/POST/DELETE методы. Проверка выполнена без учетных данных.
- Universal fallback `https://api.green-api.com/v3` остается непроверенным из-за TLS handshake `SSL_ERROR_SYSCALL` в этом окружении.
- Живая отправка не запускалась без назначенного тестового номера получателя; номер из примера документации не использовался.
