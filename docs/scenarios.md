# Сценарии

## SCN-001: Подключение инстанса

- **Актор:** пользователь.
- **Триггер:** открывает форму подключения.
- **Предусловия:** известны `idInstance` и `apiTokenInstance`.
- **Шаги:** вводит оба значения; подтверждает подключение; приложение хранит их только в памяти текущей сессии.
- **Исключения:** пустое поле блокирует продолжение; ошибка API показывается без вывода токена.
- **Результат:** форма подключения закрыта, пользователь может создать чат.
- **Требования:** REQ-F-001, REQ-F-009.

## SCN-002: Создание чата по номеру

- **Актор:** пользователь.
- **Триггер:** вводит номер и выбирает создание чата.
- **Шаги:** локальная проверка формата; `CheckAccount` с `phoneNumber`; проверка `exist`; сохранение возвращенного `chatId` и номера в состоянии интерфейса [SRC-005, SRC-010].
- **Исключения:** неподдерживаемый формат, аккаунт MAX не найден, инстанс не авторизован, ошибка или лимит API.
- **Результат:** чат создан только при `exist: true` и непустом `chatId`.
- **Требования:** REQ-F-002, REQ-F-003, REQ-F-009.

## SCN-003: Отправка текста

- **Актор:** пользователь.
- **Предусловия:** подключен инстанс и открыт чат.
- **Шаги:** вводит непустой текст до 4000 символов; отправляет; приложение вызывает `SendMessage` с `chatId` и `message`; при успехе показывает сообщение как принятое API [SRC-004].
- **Исключения:** пустой текст, превышение длины, 4xx/5xx, таймаут или отсутствие сети.
- **Результат:** текст виден в истории; при ошибке пользователь получает сообщение об ошибке и может повторить действие.
- **Требования:** REQ-F-004, REQ-F-009.

## SCN-004: Получение ответа

- **Актор:** пользователь и собеседник.
- **Предусловия:** HTTP API уведомлений включен на инстансе; polling запущен.
- **Шаги:** приложение вызывает `ReceiveNotification`; проверяет тип события и чата; добавляет поддерживаемое текстовое сообщение в интерфейс; подтверждает уведомление вызовом `DeleteNotification` с `receiptId`; повторяет polling [SRC-006–SRC-009].
- **Исключения:** таймаут без уведомления; событие другого типа; ошибка сети/API; ошибка подтверждения.
- **Результат:** входящий текст отображен в нужном чате; посторонние типы не отображаются.
- **Требования:** REQ-F-005, REQ-F-006, REQ-F-007, REQ-F-009.

## SCN-005: Завершение сессии

- **Актор:** пользователь.
- **Триггер:** нажимает выход/отключение.
- **Шаги:** polling останавливается, запрос отменяется, учетные данные удаляются из состояния приложения.
- **Результат:** API больше не опрашивается до нового подключения.
- **Требования:** REQ-F-008.

## SCN-006: Переключение темы

- **Актор:** пользователь.
- **Триггер:** нажимает кнопку переключения темы.
- **Шаги:** приложение переключает переменную темы между светлым и темным режимами.
- **Результат:** текущий экран остается доступным в выбранной теме.
- **Требования:** REQ-NF-004.
