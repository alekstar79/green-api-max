# Source Register

Дата извлечения: 2026-10-13. Поля и контракты API ниже взяты только из указанных официальных документов.

| ID      | Источник                                                                                                                                                                                        | Использовано для                                                                                | Доступ / примечание                                                          |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| SRC-001 | [GREEN-API MAX](https://green-api.com/max)                                                                                                                                                      | Подтверждение назначения MAX API и поддержки текста.                                            | Доступен.                                                                    |
| SRC-002 | [Перед началом работы](https://green-api.com/v3/docs/before-start/)                                                                                                                             | Параметры `apiUrl`, `idInstance`, `apiTokenInstance`; настройка входящих данных.                | Доступен; `apiUrl` является параметром инстанса в документации.              |
| SRC-003 | [Формат запросов](https://green-api.com/v3/docs/request-format/)                                                                                                                                | Правило формирования URL и необязательный префикс `/v3/`.                                       | Доступен; заданный универсальный хост дополнительно определен пользователем. |
| SRC-004 | [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/)                                                                                                                           | POST, `chatId`, `message`, лимит 4000 символов, `idMessage`, очередь отправки.                  | Доступен.                                                                    |
| SRC-005 | [CheckAccount](https://green-api.com/v3/docs/api/service/CheckAccount/)                                                                                                                         | POST, `phoneNumber`, формат РФ/РБ, ответ `exist`/`chatId`/`fromCache`.                          | Доступен; также перечислены ошибки формата, таймаута и лимита.               |
| SRC-006 | [Технология HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/)                                                                                                         | Настройка `webhookUrl` и типов уведомлений, FIFO, срок очереди, необходимость Receive + Delete. | Доступен.                                                                    |
| SRC-007 | [ReceiveNotification](https://green-api.com/v3/docs/api/receiving/technology-http-api/ReceiveNotification/)                                                                                     | GET, `receiveTimeout`, ответ `receiptId`/`body`, пустой ответ по таймауту.                      | Доступен; 5–60 секунд, значение по умолчанию 5 секунд.                       |
| SRC-008 | [DeleteNotification](https://green-api.com/v3/docs/api/receiving/technology-http-api/DeleteNotification/)                                                                                       | DELETE по `receiptId`, ответ `result`/`reason`.                                                 | Доступен.                                                                    |
| SRC-009 | [Входящее текстовое сообщение](https://green-api.com/v3/docs/api/receiving/notifications-format/incoming-message/TextMessage/)                                                                  | `typeWebhook`, `senderData.chatId`, `messageData.typeMessage`, `textMessageData.textMessage`.   | Доступен; для получения текста нужны оба документированных type-поля.        |
| SRC-010 | [Идентификатор чата](https://green-api.com/v3/docs/api/chat-id/)                                                                                                                                | Рекомендуемый формат chatId и предостережение при отправке по номеру вместо chatId.             | Доступен.                                                                    |
| SRC-011 | [Официальный Postman request](https://www.postman.com/green-api-2991/green-api-max/http-request/3clhrum/)                                                                                       | Сверка официальной коллекции.                                                                   | Страница доступна, подробности требуют входа; контракт подтвержден SRC-004.  |
| SRC-012 | [Форк Postman пользователя](https://alekstar-79-gmail-coms-team.postman.co/workspace/My-Workspace~403f746e-718c-4b3f-8224-cc93a106c508/collection/6653836-6bfdded3-bcdb-4c45-b940-2c91eb4c774d) | Дополнительная коллекция пользователя.                                                          | Недоступен без авторизации; перенаправляет на login.                         |
| SRC-013 | [Веб-клиент MAX](https://web.max.ru/)                                                                                                                                                           | Исследование прототипа.                                                                         | Доступен только экран входа по QR-коду/номеру; интерфейс чата [UNVERIFIED].  |
| SRC-014 | [Vite: Env Variables and Modes](https://vite.dev/guide/env-and-mode.html)                                                                                                                       | Экспорт `VITE_` через `import.meta.env`; unprefixed env не доступен клиенту.                    | Официальная документация, получена через Context7.                           |
| SRC-015 | [React: useEffect](https://react.dev/reference/react/useEffect)                                                                                                                                 | Cleanup effect при смене зависимостей и unmount для остановки polling.                          | Официальная документация, получена через Context7.                           |

| SRC-016 | [Ограничение частоты запросов](https://green-api.com/v3/docs/api/ratelimiter/) | Per-instance per-second limits для CheckAccount, SendMessage, ReceiveNotification и DeleteNotification. | Официальная документация; превышение лимита возвращает HTTP 429. |

Проверка CORS: `OPTIONS` на тестовом кластерном хосте вернул `204` с `Access-Control-Allow-Origin: *`. Аналогичный запрос к `api.green-api.com` завершился `SSL_ERROR_SYSCALL`; браузерная доступность универсального хоста не проверена. Эти проверки не являются контрактом документации.
